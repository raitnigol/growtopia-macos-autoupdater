GROWTOPIA / MAC LAUNCHER · 2.1.0

Growtopia Launcher

Installation and usage instructions.

1. Open the application

  1. Download growtopia-launcher-macos-2.1.0.zip and double-click it in Finder.
  2. Open the extracted folder. Double-click Growtopia Launcher.app.
  3. The launcher window opens. It shows your installed game’s bundle version, the selected download source, preferences, and update controls.
First-open security prompt: this independent app is not Developer ID signed or notarized. macOS may block its first launch. If you choose to trust this copy, attempt to open it once, then use System Settings → Privacy & Security → Open Anyway and authenticate if requested. This is a one-time approval for this launcher build; it is separate from the game’s trust setting. Global Gatekeeper settings are not disabled.

2. Install the launcher into Applications

  1. Click Install Launcher at the top right of the window.
  2. The app copies itself into ~/Applications/Growtopia Launcher.app. A matching older launcher can be replaced; unrelated apps are refused.
  3. Click Show Applications when installation finishes. Close the downloaded copy, then open the installed copy.
  4. Drag the installed Growtopia Launcher.app to your Dock for future use.

To find your personal Applications folder in Finder, press ⇧ ⌘ G, enter ~/Applications, and press Return. It can differ from the Applications folder in Finder’s sidebar.

You can also run the app directly without copying it; installing it gives you a stable place for your Dock icon.

3. Choose how game downloads are trusted

The checkbox Trust official downloads for Growtopia only controls the managed game, not this launcher’s initial approval.

  • Unchecked: normal macOS first-open checks remain. An unnotarized game build may still need Open Anyway.
  • Checked: after an explicit confirmation, remembers permission to remove quarantine from staged Growtopia downloads from the selected official source, including future updates. This can skip the repeated first-open/notarization check.
Trusting the download does not establish that an unsigned game is safe. Broken signatures, unexpected bundle IDs, and changes to a pinned publisher team are still refused. Other macOS protections or organization policies may still block software.

4. Install, update, and play

  1. Close Growtopia if it is already running.
  2. Click Install & Play, or Update & Play when a managed game is installed.
  3. Watch the status and download progress in the window. The first run downloads the full DMG, including when a game was already present.
  4. The launcher checks and stages the app, replaces the managed copy, keeps a previous version, ejects the image, and opens Growtopia.
  5. Log in inside the game normally. The launcher does not enter or store your GrowID or password.

The window stays available while the game opens. For daily use, open the launcher from your Dock and click Update & Play.

What the window tells you

Installed GameVersion metadata from the managed Growtopia.app. It can differ from the version shown inside the game.
Official DownloadWhat the launcher knows about the chosen download. “Download needs inspection” means it needs to fetch and inspect the bundle; it does not prove a newer game version exists.
Download modifiedThe server’s HTTP Last-Modified timestamp, not a verified release date.
ProgressDownload percentage when the server supplies a size; an indeterminate indicator during checks, verification, and staging.

The download headers do not contain a reliable “latest game version.” The launcher displays an actual downloaded bundle’s version only after inspecting that bundle. It does not guess 5.61 from a timestamp or file size.

Troubleshooting

The game still says “Update Required”

Quit Growtopia and click Download Again. Then use Launch Installed. If the client is still old, choose the other official source and run Update & Play. Neither source is guaranteed to publish the server-required version at all times; the launcher cannot manufacture a missing release.

The game is running

The launcher does not replace a running game. Close Growtopia and retry. Choosing Open Running Game opens the existing client.

Replacing /Applications/Growtopia.app fails

Click Use Personal Folder, then Install & Play. The original global installation remains. Use the launcher to avoid opening that old copy by accident.

The window reports a signature or package-layout error

Click Open Log and keep the error. The app stops instead of installing an unexplained payload. Do not disable validation to push it through.

The app does not open its window

Review the first-open security approval above. If it launches but errors, inspect ~/Library/Logs/Growtopia Launcher UI.log. This native interface has not been exercised on a Mac in the build environment; the UI log is the useful diagnostic for a startup issue.

Installer cleanup and diagnostics

The updater deletes its own temporary download and staging files, and ejects the image on normal completion or handled failure. Browser-downloaded copies are separate: use Remove Installers to choose Growtopia DMGs and move them to Trash. It does not clear game settings, cookies, saved sessions, or arbitrary Downloads files.

For a bug report, choose Growtopia Launcher → Copy Diagnostics in the application menu. Review and paste that report into the GitHub issue form. It omits usernames, serial numbers, home paths, login data and raw logs.

Files, compatibility, and removal

The app is built for Apple Silicon and Intel, targeting macOS 11 or later. Open the application directly; no additional software is required.

Your previous launcher settings are reused from ~/Library/Application Support/Growtopia Launcher. The worker log is ~/Library/Logs/Growtopia Launcher.log. The previous game is a hidden sibling called .Growtopia.previous.app.

To remove the helper, quit it and move ~/Applications/Growtopia Launcher.app to the Trash. You may also remove the old separate Growtopia Launcher Settings.app if present. The game, backup, settings, and logs are left in place unless you remove them separately. There is no background service or scheduled task.
