# v2.1.0

Mac application for installing, updating, and launching Growtopia from its official Mac download entry points.

## Included

- A native interface with installed-version information, update checks, download progress, and launch controls.
- Staged game replacement, one previous-version backup, rollback, and cancellation after a safe step.
- Selection between the in-game Ubisoft CDN and official website beta download.
- A per-game trust preference; global Gatekeeper settings are not disabled.
- Explicit selection of browser-downloaded Growtopia DMGs for removal to the Trash.
- **Copy Diagnostics** in the app menu, a command-line diagnostic wrapper, and issue-report forms.
- Installation, usage, and troubleshooting documentation.
- The startup background-colour fix introduced in 2.0.1 and plain functional interface text.

The application does not bundle Growtopia, store account passwords, prepopulate the login flow, or rewrite its HTML login page.

## Recorded result

A user confirmed a successful **Growtopia 3.82 → 5.61** update and subsequent game launch. The exact launcher build used for that report was not recorded. The old 3.82 client came from a third-party source; the result does not verify that old binary's authenticity or safety.

The user's supplied report identifies an **ARM64 Mac, model Mac16,8**, and **macOS 27.0.1 (26A434)**. These are the reported values; other macOS versions and Intel hardware do not yet have a recorded manual result.

## Installation

Download the application ZIP asset, extract it, and open **Growtopia Launcher.app**. Use **Install Launcher** to copy it into your personal Applications folder, then use **Install & Play** or **Update & Play**.

The launcher is not Developer ID signed or notarized. macOS may require an initial **Open Anyway** approval. An ad-hoc signature does not establish an Apple-issued developer identity.

## Limits

HTTP metadata does not prove which game version the server download contains. The displayed version is read from an installed or downloaded bundle and can differ from the version shown in-game. The game server can reject an old client even when it launches.

Portable automated tests use mocked macOS commands. The macOS workflow is configured to run native GUI-startup and Foundation Trash smoke checks; see its run for the actual result. A successful build is not a manual test of every hardware and OS combination. Report failures through the repository's bug form with the launcher version, environment, exact action, and relevant sanitized error.
